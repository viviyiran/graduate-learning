## 3. Git 与 VS Code

进一步熟悉了 VS Code 中 Git 的使用。

今天理解了：

- VS Code 可以自动识别当前文件夹中的 Git 仓库。
- “源代码管理”可以查看当前文件的修改状态。
- `commit` 只是把修改提交到本地 Git 仓库。
- `push` 才是把本地提交上传到 GitHub。
- VS Code 本身也可以进行 commit 和 push，不一定每次都需要打开 Git Bash。
- GitLens 可以查看提交历史、文件修改历史等更详细的 Git 信息。

Git 的基本流程进一步明确为：

```text
修改文件
    ↓
git add
    ↓
git commit
    ↓
git push
    ↓
GitHub
```

## 4. .gitignore

今天新增了 `.gitignore` 文件。

目前加入：

```gitignore
*.exe
```

目的是忽略 C++ 编译后生成的 `.exe` 文件，避免将没有必要的可执行文件提交到 GitHub。

同时理解了：`.gitignore` 主要用于告诉 Git 哪些文件不需要进行版本管理。

例如 C++ 项目中通常需要保留源码和学习笔记，如：

```text
.cpp
.md
```

而编译产生的：

```text
.exe
```

通常没有必要上传。
