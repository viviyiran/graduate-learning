## 2. 数组的基本特点

数组中的元素在内存中是连续存储的。

例如：

```cpp
int a[5] = {10, 20, 30, 40, 50};
```

对应下标：

```
下标：0   1   2   3   4
元素：10  20  30  40  50
```

数组下标从 `0` 开始。

已知下标时，可以直接访问元素：

```
cout << a[2];
```

输出：

```
30
```

时间复杂度：

```
O(1)
```

------

## 3. 数组遍历

如果要访问数组中的所有元素，可以使用 `for` 循环：

```
for (int i = 0; i < length; i++)
{
    cout << a[i] << " ";
}
```

如果数组有 `n` 个元素，需要访问大约 `n` 次。

时间复杂度：

```
O(n)
```

------

## 4. 顺序查找

如果只知道要找的值，不知道它的下标，需要从头开始逐个比较。

例如查找 `50`：

```
10 → 20 → 30 → 40 → 50
```

最坏情况下需要检查全部 `n` 个元素。

时间复杂度：

```
O(n)
```

注意区别：

```
已知下标访问：O(1)
不知道下标，查找某个值：O(n)
```

## 5. 数组插入

假设原数组为：

```
10 20 30 40 50
```

如果要在中间插入一个元素，就必须先给新元素腾出位置。

### 移动方向

插入时必须：

```
从后往前移动
```

例如要在 `30` 前插入元素：

```
先移动 50
再移动 40
再移动 30
```

原因：

如果从前往后移动，会把后面还没有移动的数据提前覆盖掉。

核心思想：

```
a[i] = a[i - 1];
```

移动完成以后，再把新元素放入空出来的位置。

### 复杂度

中间插入最坏情况下需要移动接近 `n` 个元素。

时间复杂度：

```
O(n)
```

如果直接在原数组上移动，只使用少量辅助变量：

空间复杂度：

```
O(1)
```

## 6. 数组删除

假设原数组：

```
10 20 30 40 50
```

删除下标 `2` 的 `30`：

```
10 20 30 40 50
      ↑
```

需要把后面的元素依次向前移动：

```
40 → 30 的位置
50 → 40 的位置
```

最终有效数组：

```
10 20 40 50
```

### 移动方向

删除时必须：

```
从前往后移动
```

核心代码：

```
for (int i = index; i < length - 1; i++)
{
    a[i] = a[i + 1];
}

length--;
```

原因：

如果从后往前移动，会提前覆盖下一步仍然需要使用的数据。

### 关于 length

执行删除以后：

```
length--;
```

例如：

```
删除前：
10 20 30 40 50

内存中移动后：
10 20 40 50 50
```

最后一个 `50` 可能仍然存在于内存中。

但是：

```
length = 4;
```

因此只有：

```
10 20 40 50
```

属于当前有效数组。

### 复杂度

如果删除第一个元素，需要移动：

```
n - 1
```

个元素。

因此最坏时间复杂度：

```
O(n)
```

算法没有创建一个随 `n` 增长的新数组，只使用了少量变量。

空间复杂度：

```
O(1)
```

------

## 7. 插入和删除方向对比

这是目前最容易混淆的地方。

```
插入：从后往前移动
删除：从前往后移动
```

### 插入

```
← 移动方向

10 20 30 40 50
```

目的是给新元素腾位置。

### 删除

```
移动方向 →

10 20 30 40 50
```

目的是让后面的元素填补前面的空位。

记忆方法：

```
插入：往后腾位置，所以从后开始搬。
删除：往前补空位，所以从前开始搬。
```

## 8. 时间复杂度总结

| 操作         | 时间复杂度 |
| ------------ | ---------- |
| 已知下标访问 | O(1)       |
| 遍历数组     | O(n)       |
| 顺序查找     | O(n)       |
| 中间插入     | O(n)       |
| 中间删除     | O(n)       |

插入和删除如果采用原地移动：

```
空间复杂度：O(1)
```

## 9. 本阶段容易出错的地方

### 1. 把数组访问误认为 O(n)

错误：

```
访问 a[3] 需要查找，所以是 O(n)
```

正确：

```
已知下标可以直接定位，所以是 O(1)
```

### 2. 插入移动方向记反

正确：

```
插入：从后往前
```

否则会覆盖还没有移动的数据。

### 3. 删除移动方向记反

正确：

```
删除：从前往后
```

否则同样会覆盖后续仍需要的数据。

### 4. cout 输出 i 和 a[i] 混淆

```
cout << i;
```

输出的是下标。

```
cout << a[i];
```

输出的是数组元素。

g++ array_delete.cpp -o array_delete

.\array_delete.exe
